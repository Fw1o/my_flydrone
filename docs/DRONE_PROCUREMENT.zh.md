## 2. 背景:为什么不能"随便买一架能编程的无人机"

> **背景**:四旋翼只能被 4 个量控制 —— `throttle`(升降)、`pitch`(前后)、`roll`(左右)、`yaw`(转向)。
> 我们的代码输出的是**这 4 个摇杆值**(不是电机 PWM),电机转速由飞机自己的飞控去算。
> 所以选型的关键不是"性能多强",而是:**能不能把 4 个轴都交给程序** + **能不能拿到视频** + **有没有位置反馈**。

三条硬性筛选条件:

| 条件 | 为什么必须 | 不满足的后果 |
|---|---|---|
| **开放 SDK(能发 4 轴指令)** | 我们要接管 pitch/roll/yaw/throttle | 只能像 iDrone 那样焊遥控器,一次只能偷一个轴 |
| **有摄像头(或能外挂)** | 果蝇脑的输入是视觉 | 只能用手势模式,而笔记本摄像头读一帧要 **35 ms** → 实测超 20 Hz 预算 |
| **有位置/速度反馈** | 没有它,飞机永远只能"漂着升降" | 无法定点悬停、无法"飞到某处" |

## 3. 本机能力基线(实测,不是估算)

先确认"用现有笔记本够不够":

| 项目 | 实测值 |
|---|---|
| CPU | i7-12700H(14 核 20 线程) |
| GPU | RTX 3060 Laptop 6 GB(30 SM / 336 GB/s) |
| **全量 166,700 神经元** | GPU **1.02x** 实时 |
| **core-hops 2(107,064)** | GPU **1.72x** |
| **core-hops 1(18,726)** | GPU **3.65x** |
| MiniFly(858) | CPU **10–15x** |
| 摄像头读帧 | **35 ms/帧**(笔记本内置) |
| `retina.encode`(真实帧) | 5 ms |

**每 tick 预算(20 Hz = 50 ms)对照**:

| 组合 | 每 tick | 能否 20 Hz |
|---|---|---|
| **core1 + `--input camera`** | **25.4 ms** | ✅ 余量 24 ms |
| **core2 + `--input camera`** | **37.5 ms** | ✅ 余量 12 ms |
| core1 + `--input gesture` | 60.5 ms | ❌ 超 10 ms |
| core2 + `--input gesture` | 72.6 ms | ❌ 超 23 ms |

**结论:本机完全够用,不需要买主机。** 前提是**用飞机自带的视频流**(`--input camera`),而不是笔记本摄像头。

## 5. 推荐方案详解

### ① Tello(第一台,验证链路)

**为什么先买它**:代码零改动就能用 —— `djitellopy 2.5.0` 已装在 `venv-gpu`,视频流是后台线程解码(取帧几乎零成本),`--input camera` 实测 25.4/37.5 ms 满足 20 Hz。

**采购清单**:

| 项 | 说明 | 参考价 |
|---|---|---|
| Tello 机身(二手/库存) | 优先选**带原盒、电池健康**的 | ¥600–1100 |
| **备用电池 ×2–3** | 停产机型电池是最大风险,必须多买 | ¥80–150/块 |
| 桨叶保护罩 | 室内必备 | ¥30–60 |
| 备用桨叶 | 易损 | ¥20–40 |
| **合计** | | **¥700–1300** |

**买前必查**(二手尤其重要):
1. 能否正常开机、连 `TELLO-XXXXXX` WiFi
2. 电池循环次数 / 是否鼓包
3. 四个电机是否都能正常转动、有无异响
4. 摄像头画面是否正常(这是我们的"眼睛",坏了就没用)

### ② Pixhawk 小四轴 + 光流(第二台,解决定点)

**为什么买它**:它解决的是**根本问题** —— 没有位置反馈,果蝇脑再准也只能让飞机"漂着升降"。而 PMW3901 光流 + VL53L1X 激光的组合,能把"定点悬停"做到厘米级,而且**有公开的完整教程**。

**采购清单**:

| 项 | 型号 | 参考价 |
|---|---|---|
| 飞控 | **Pixhawk 2.4.8 / PX4**(ArduPilot 亦可) | ¥360–760 |
| 机架 | 250–450 mm 室内小机架 | ¥80–200 |
| 电机 ×4 + 电调 ×4 | 2205/2306 级 | ¥200–350 |
| 桨叶 | 5–7 寸 | ¥30 |
| 电池 ×2 | 3S/4S 1500–2200 mAh | ¥150–300 |
| 遥控器 + 接收机 | 用于手动接管/紧急切换 | ¥200–400 |
| **光流模块** | **PMW3901** | ¥100–200 |
| **激光测距** | **VL53L1X** | ¥50–100 |
| 摄像头 | USB 摄像头或树莓派摄像头 | ¥100 |
| **合计** | | **¥1200–2200** |

**关键配置**(决定了它比 Tello 强在哪):

```
ArduPilot / PX4 参数:
  EK3_SRC1_POSXY = 0     # 水平位置用光流
  EK3_SRC1_VELXY = 5     # 速度用光流
  EK3_SRC1_POSZ  = 2     # 高度用激光/气压
  FLOW_TYPE      = 1     # PMW3901
  RNGFND1_TYPE   = 20    # VL53L1X
```

配好后即可实现**室内定点悬停**(无需 GPS、无需动捕)。

## 6. 采购后的验证流程(照做即可)

### 第 0 步:到货前先跑通仿真

```powershell
$py  = "E:\pycharm_pro\pro_project\FlyDrone\venv\Scripts\python.exe"
$pyg = "E:\pycharm_pro\pro_project\FlyDrone\venv-gpu\Scripts\python.exe"
cd "E:\pycharm_pro\pro_project\FlyDrone\FlyDrones"

# GPU 后端正常?
& $pyg -m flydrones bench --brain data\malecns_core2_v2.npz --backend torch `
      --config configs\fly_core2.yaml --ms 1000        # 应约 1.8x

# 仿真端到端
& $pyg -m flydrones fly --drone sim --config configs\fly_core2.yaml `
      --input camera --seconds 10
```

### 第 1 步:Tello 到手 → DRY RUN(不飞)

```powershell
# 连上 TELLO-XXXXXX 的 WiFi,然后:
& $pyg -m flydrones fly --drone tello --config configs\fly_core2.yaml `
      --config configs\tello.yaml --input camera --seconds 10
# 看到 [dry-run] would connect to tello + 指令输出 = 通路正常
```

### 第 2 步:**拆桨** + `--send`

```powershell
# 桨叶全部拆掉!观察电机转向是否符合指令
& $pyg -m flydrones fly --drone tello --config configs\fly_core2.yaml `
      --config configs\tello.yaml --input camera --send --seconds 10
```

### 第 3 步:护桨 + 空旷室内低飞

```powershell
# 立好围栏(默认 1.5 m),软垫铺地,人在 3 m 外
& $pyg -m flydrones fly --drone tello --config configs\fly_core1.yaml `
      --config configs\tello.yaml --input camera --send --seconds 30 --log flight.csv
```

> **为什么用 `fly_core1.yaml`**:core-hops 1 只有 18,726 神经元,本机 3.65x 实时,余量最大。
> 稳定后再换 `fly_core2.yaml`(1.72x,带前向控制)。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| **Tello 电池老化** | 续航骤降、空中断电 | 多买 2–3 块;首飞前满电测试;**低电量自动降落**已在安全层里 |
| Tello 配件断供 | 炸机后无法修 | 同时买备用桨/护罩;或用 ② 方案做备份平台 |
| 室内气流/漂移 | 撞墙 | 护桨 + 围栏(`geofence_radius_m`)+ 软垫 |
| **视频延迟 100–200 ms** | 逃逸反射来不及 | 降低期望:先验证"升降+转向",不要指望"高速躲障" |
| 首次实飞未知 | 可能失控 | **拆桨 → 护桨低飞 → 正常飞**,三步走,别跳 |
| Ctrl+C 的处理 | 会悬停而非掉下来(见 `docs/FLIGHT.zh.md` §0.1) | 首飞前读一遍 |
